# Лабораторна робота № 3

**Тема:** Створення простого десктопного додатку

## Теоретичні відомості

### Electron

Electron — це фреймворк для розробки кросплатформних десктопних додатків із використанням веб-технологій: HTML, CSS та JavaScript. В основу роботи фреймворку покладено поєднання рушія Node.js та браузерного рушія Chromium.

Принцип роботи Electron базується на двох типах процесів.

**Основний процес (Main Process)** — відповідає за інтеграцію та взаємодію з графічним інтерфейсом операційної системи. До його функцій належать: інтеграція з панеллю задач (Windows) або Dock (macOS), керування системним треєм, повноекранний режим та інші нативні можливості ОС. Основний процес запускається один раз протягом усього життєвого циклу застосунку.

**Процес рендерингу (Renderer Process)** — відповідає за відображення вікна браузера, в якому завантажується вміст сторінки додатку або будь-яка інша веб-сторінка. Таких процесів може існувати довільна кількість. Кожен процес рендерингу породжується основним процесом.

Під час запуску застосунку Electron виконує наступні кроки:
1. Зчитується файл `package.json`, в якому визначено секцію `main` із вказівкою на точку входу.
2. Обробляється точка входу та створюється основний процес.
3. Основний процес, за бажанням розробника, відкриває одне або кілька вікон браузера, тобто породжує процеси рендерингу.

### IPC (Inter-Process Communication)

Для передачі даних між основним процесом та процесом рендерингу в Electron використовується механізм міжпроцесної взаємодії — IPC. Передача даних здійснюється за допомогою модулів `ipcMain` (в основному процесі) та `ipcRenderer` (в процесі рендерингу).

Для безпечної передачі даних з основного процесу до рендерера застосовується `contextBridge`, який створює міст між Node.js-середовищем та веб-контекстом сторінки.

### Axios

Для виконання HTTP-запитів до зовнішніх API в Electron-застосунках використовується бібліотека Axios. Вона забезпечує зручний інтерфейс для виконання асинхронних запитів та обробки відповідей.

### React

React — це JavaScript-бібліотека для побудови інтерфейсів користувача. Electron-застосунок може використовувати React як фреймворк для рендерингу інтерфейсу. Збірка React-проекту виконується командою `npm run build`, після чого папку зі збіркою підключають до Electron через завантаження відповідного `index.html`.

### TypeScript

TypeScript — це мова програмування, що є надмножиною JavaScript і забезпечує статичну типізацію. Використання TypeScript в Electron-проекті дозволяє виявляти помилки на етапі компіляції та покращує читабельність коду.

### Webpack

Webpack — це інструмент для збірки модулів. В даному проекті Webpack використовується для транспіляції TypeScript-файлів та об'єднання залежностей в єдині вихідні файли для основного процесу (`main.js`) та процесу рендерингу (`renderer.js`).

### Material UI (MUI)

Material UI — це бібліотека React-компонентів, що реалізує дизайн-систему Material Design від Google. Використовується для швидкої побудови естетично оформленого та функціонального інтерфейсу користувача.

## Хід роботи

### 1. Структура проекту

У ході виконання лабораторної роботи було створено десктопний застосунок для відображення погоди в Україні з використанням таких технологій: Electron, React, TypeScript, Webpack та Material UI.

Структура проекту має наступний вигляд:

```
CPP_LR03/
├── src/
│   ├── main.ts                 # Основний процес Electron
│   └── renderer/
│       ├── index.html          # Шаблон HTML-сторінки
│       ├── index.tsx           # Точка входу React-застосунку
│       ├── App.tsx             # Головний React-компонент
│       └── types.ts            # TypeScript-інтерфейси
├── package.json
├── tsconfig.json
└── webpack.config.js
```

### 2. Налаштування проекту

Проект було ініціалізовано з наступними залежностями. Для виробничого середовища встановлено: `electron`, `electron-builder`, `react`, `react-dom`, `axios`, `@mui/material`, `@mui/icons-material`, `@emotion/react`, `@emotion/styled`. Для розробки встановлено: `typescript`, `webpack`, `webpack-cli`, `ts-loader`, `html-webpack-plugin`, `copy-webpack-plugin`, `@types/node`, `@types/react`, `@types/react-dom`.

У файлі `package.json` визначено наступні скрипти:
- `build` — виконує збірку проекту за допомогою Webpack;
- `start` — виконує збірку та запускає Electron-застосунок;
- `dev` — запускає Webpack у режимі відстеження змін файлів.

### 3. Основний процес (main.ts)

В файлі `src/main.ts` реалізовано основний процес застосунку. Функцією `createWindow()` створюється вікно браузера розміром 1200×800 пікселів. В налаштуваннях вікна вказано `nodeIntegration: true` та `contextIsolation: false`, що дозволяє використовувати Node.js API безпосередньо в процесі рендерингу. Слід зазначити, що така конфігурація не рекомендована для виробничих застосунків, оскільки відкриває доступ до системних ресурсів із веб-контексту. В реальних проектах рекомендується використовувати `contextIsolation: true` у поєднанні з `contextBridge` для безпечного обміну даними між процесами.

Для завантаження вмісту вікна використовується метод `mainWindow.loadFile()`, якому передається шлях до зібраного файлу `index.html`:

```typescript
mainWindow.loadFile(path.join(__dirname, 'index.html'));
```

Також реалізовано обробку подій життєвого циклу застосунку: відкриття нового вікна при повторній активації застосунку (`activate`) та коректне завершення роботи при закритті всіх вікон (`window-all-closed`).

### 4. Процес рендерингу (React + TypeScript)

Для відображення інтерфейсу використано React-застосунок.

**Типи даних (`types.ts`):**

Визначено два TypeScript-інтерфейси:
- `WeatherData` — описує структуру запису про погоду: тип (`current` або `hourly_forecast`), локацію, температуру, стан погоди, дату та час.
- `GroupedWeatherData` — описує згруповані дані по місту: локацію, поточну погоду та список прогнозів.

**Точка входу (`index.tsx`):**

Ініціалізовано тему Material UI у темному режимі з фірмовими кольорами (`#667eea`, `#764ba2`). Виконано монтування React-застосунку в DOM-елемент з ідентифікатором `root`.

**Головний компонент (`App.tsx`):**

Реалізовано функціональний компонент `App`, в якому:
- Стан застосунку включає масив згрупованих даних про погоду (`weatherData`), прапорець завантаження (`loading`) та рядок помилки (`error`).
- Функція `fetchWeatherData` виконує GET-запит до локального API (`http://localhost:3000/api/weather`) за допомогою axios, після чого отримані дані групуються за локацією за допомогою функції `groupByLocation`.
- Дані завантажуються автоматично при монтуванні компонента через хук `useEffect`.
- Інтерфейс відображає: панель навігації з назвою застосунку та кнопкою оновлення; індикатор завантаження; повідомлення про помилку; картки міст з поточною погодою та прогнозом.

### 5. Збірка за допомогою Webpack

В файлі `webpack.config.js` налаштовано два окремих конфігураційних об'єкти для збірки:
- **Основного процесу**: TypeScript-файл `src/main.ts` компілюється з target-параметром `electron-main` та виводиться як `dist/main.js`.
- **Процесу рендерингу**: TypeScript/TSX-файли компілюються з target-параметром `electron-renderer`, генерується `dist/renderer.js`, а HTML-шаблон обробляється плагіном `HtmlWebpackPlugin`.

### 6. Запуск застосунку

Для запуску застосунку виконується команда:

```bash
npm run start
```

Ця команда послідовно виконує збірку Webpack та запускає Electron, який завантажує зібраний застосунок.

### 7. Результат

В результаті виконання лабораторної роботи було створено функціональний десктопний застосунок для відображення погоди в Україні. Застосунок побудовано на основі Electron із використанням React та TypeScript для рендерингу інтерфейсу. Інтерфейс реалізовано з використанням бібліотеки Material UI та містить: заголовок із назвою застосунку та кнопкою оновлення даних; картки для кожного міста з відображенням поточної температури, стану погоди, дати та часу; список прогнозів для кожного міста.

Дані завантажуються з зовнішнього API за допомогою бібліотеки axios, яка підключена в процесі рендерингу. Застосунок коректно обробляє стани завантаження та помилок, відображаючи відповідні повідомлення користувачу.

Отримано практичні навички з налаштування проекту на основі Electron + React + TypeScript, конфігурування Webpack для збірки двох окремих процесів, а також реалізації отримання та відображення даних із зовнішнього API. Застосування сучасних інструментів розробки, таких як TypeScript та Material UI, дозволило створити типізований, підтримуваний та естетично оформлений десктопний застосунок.
